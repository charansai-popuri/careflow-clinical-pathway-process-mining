# BigQuery Setup

## Purpose
BigQuery is the warehouse that stores the raw ER event log
generated by the Python script. dbt and PM4Py will read from it later.

## Planned layout
| Item | Value |
|---|---|
| Dataset | careflow_raw |
| Table | event_log_raw |
| Region | asia-south1 (Mumbai) |
| Source file | data/event_log.csv |
| Schema file | bigquery/schema.json |

## Schema
| Column | Type | Mode |
|---|---|---|
| Case_ID | STRING | REQUIRED |
| Activity | STRING | REQUIRED |
| Timestamp | TIMESTAMP | REQUIRED |
| Condition | STRING | REQUIRED |
| Age_Group | STRING | REQUIRED |
| Ward | STRING | NULLABLE |

Ward is the only nullable column because it is filled only on the
Ward Admission step.

## Checks before loading
- CSV header matches the schema column order.
- All 68,440 timestamps are valid.
- No required column has blank values.

## Expected result after load
68,440 rows and 10,000 distinct patients.
